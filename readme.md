# Student Record System

A simple python-based student record system developed using object-oriented programming (OOP).

## OOP Concepts Used

- Class and objects
- Attributes
- Instance methods
- Class methods
- Object interaction

## Data Structure

The project uses a python list to store multiple Student objects.

## Privacy

This project uses fictional student information for demonstration purposes only. It does not store sensitive personal information such as passwords, phone numbers, home addresses, medical information, or financial details.

## Open Source

This project is open-source and available on GitHub for learning and educational purposes.

## Accessibility and Inclusion

The project uses simple python code and clear output messages to make student records easy to understand.

## Modular and Reusable Design

The project is organized into separate classes for students and courses. Methods can be reused to display student information, enroll students in courses, and add student records to a list.

## Example Usage

Run the program using Python:

python main.py

The program displays student information, course information, student enrollment, and the university name.
